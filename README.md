# Peace Health Android App

প্রথম version: Peace Health — Diagnostic Centre & Polyclinic.

Included home screen:
- Blood Test Booking
- X-Ray / USG / ECG
- Doctor Appointment
- Home Blood Collection
- My Reports
- Test Price List
- Contact Centre

Build:
1. Open this project in Android Studio.
2. Let Gradle sync.
3. Select `app`.
4. Build > Build APK(s).

The next version can add real booking forms, WhatsApp/call buttons, doctor schedules, price data, reports and notifications.
